# Register Suite v4

[English Description]
A powerful, web-based tool for teachers to manage school registers, generate PDFs, and format data efficiently. Built for speed and reliability.

[ગુજરાતી વર્ણન]
રજીસ્ટર સૂઈટ (Register Suite v4) એ શિક્ષકો માટે બનાવવામાં આવેલું એક અત્યંત સચોટ અને ઉપયોગી સોફ્ટવેર છે. જેની મદદથી તમે હાજરી પત્રક, માર્કશીટ અને અન્ય શૈક્ષણિક દસ્તાવેજોને વ્યવસ્થિત રીતે PDF માં ફેરવી શકો છો.

## Features | મુખ્ય વિશેષતાઓ

* **Data-Driven Architecture:** Accurate and stable data management.
* **Easy PDF Generation:** Print-ready legal/A4 formats.
* **Dynamic Customization:** Manage columns and styling with ease.

* **ડેટા-ડ્રિવન:** એકદમ સચોટ અને સુરક્ષિત ડેટા મેનેજમેન્ટ.
* **PDF જનરેશન:** શિક્ષકો માટે Legal અને A4 સાઈઝમાં પ્રિન્ટ માટે તૈયાર.
* **કસ્ટમાઇઝેશન:** તમારી જરૂરિયાત મુજબ કોલમ અને ફોન્ટની પસંદગી.

## Getting Started | કેવી રીતે શરૂ કરવું

1. Clone this repository: `git clone https://github.com/yourusername/register-suite.git`
2. Open `index.html` in your browser.
3. Upload your Excel/Worksheet data and start formatting!

૧. રિપોઝીટરી ક્લોન કરો.
૨. `index.html` ને તમારા બ્રાઉઝરમાં ઓપન કરો.
૩. તમારી એક્સેલ ફાઈલ અપલોડ કરો અને કામ શરૂ કરો!
